# ECON1626 Labour Policy Proposal

Policy proposal for ECON1626 Assessment 2: how South Australia should respond to AI's impacts on the aged care workforce, framed as a submission to the SA Royal Commission into Artificial Intelligence.

## Repository contents

| File | Description |
|---|---|
| [`proposal.md`](proposal.md) | The policy brief |
| [`reflection.md`](reflection.md) | AI use reflection (200 words) |
| `figures/` | Figures used in the proposal (if any) |

## How to read this repository

Start with the Executive Summary in `proposal.md`. The options evaluation matrix is in Section 3 and the implementation plan is in Section 4. The commit history shows how the proposal was developed.
